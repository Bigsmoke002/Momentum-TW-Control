# GEMINI.md

Read and follow [AGENTS.md](AGENTS.md) — it contains all project rules.

Most important rule: this repository is public — **never commit or push private
information** (MAC addresses, home paths, IPs, e-mails, tokens, passwords, personal data).
Detect devices at runtime instead of hard-coding them, run `scripts/check-private.sh`
before committing and never use `--no-verify`.
